# Music Library API

## Run

```bash
npm install
npm run start
```

API runs on `http://localhost:3001`.

## Endpoints

- `GET /health`
- `GET /api/songs`
- `GET /api/songs/:id`
- `POST /api/songs`
- `PUT /api/songs/:id`
- `DELETE /api/songs/:id`

## Test

```bash
npm test
```

## Generate APIDOC

```bash
npm run apidoc
```
