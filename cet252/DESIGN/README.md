# DESIGN Evidence

Place your design artifacts in this folder:

- `lofi-wireframes.pdf` (or images such as `lofi-01.png`, `lofi-02.png`)
- `figma-link.txt` containing your shared Figma URL
- `figma-design-mode.png` screenshot
- `figma-prototype-mode.png` screenshot

- CRUD screens represented in wireframes and high-fidelity design
- Realistic data and high-quality imagery
- Interactive prototype navigation evidence
