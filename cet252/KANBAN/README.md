# KANBAN Evidence

Place your Trello board evidence in this folder.

## Add these files

- `board-link.txt` - public/shared board URL
- `board-overview.png` - screenshot showing To Do / Doing / Done lists
- `cards-back-details.png` - screenshot(s) showing user story, acceptance criteria, and functionality notes
- `labels-usage.png` - screenshot showing labels/tags/categories use
- `kanban-recording-link.txt` - short screen recording link for board walkthrough

## Board minimum requirements

- Lists: To Do, Doing, Done
- Cards in To Do represent user stories/tasks
- Card backs include acceptance criteria and functionality notes
- Use labels/tags/categories consistently
