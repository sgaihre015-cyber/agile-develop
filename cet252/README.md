# CET252 Submission Package

This folder contains the assessment submission package for Portfolio Task B2.

## Included components

- `API/` - Node/Express REST API, SQLite database, tests, package files.
- `CLIENT/` - Client application, README, tests, package files.
- `APIDOC/` - Generated API documentation website.
- `DESIGN/` - Lo-fidelity wireframes and high-fidelity Figma evidence placeholders.
- `KANBAN/` - Trello board evidence placeholders (board link, screenshots/recording notes).
- `SCREENCAST/` - Final screencast evidence placeholders and checklist.

## Pre-submit checks

From `API/`:

```bash
npm install
npm test
npm run apidoc
```

From `CLIENT/`:

```bash
npm install
npm test
```

Zip only this `cet252` directory for submission (exclude `node_modules`).
